# MeshVPS — серверный установщик 0.1.35

Для Debian / Ubuntu x86_64 с systemd 247 или новее. VPS должен иметь исходящий HTTPS до GitHub и возможность установить системные зависимости. Выполните `sudo -i`, затем короткую команду из актуального клиента MeshVPS: кнопка «Установка VPS…» в основном окне.

Клиент скачивает установщик из закреплённой Git-ревизии и проверяет SHA-256 до запуска. Это позволяет установить серверную часть через консоль хостинга при недоступном прямом SSH. После установки клиент 0.1.35 может зарегистрировать ПК через GRE по SSH-логину и паролю без копирования большого скрипта или кода подключения. При первом публичном подключении проверьте SSH-отпечаток по данным консоли хостинга.

Для ручного скачивания: [установщик](https://raw.githubusercontent.com/3ont666/meshvps-releases/a2537ca3ab5b34d06f22fe0d66fb9463ba79b54c/v0.1.35/meshvps-install.sh), [SHA-256](https://raw.githubusercontent.com/3ont666/meshvps-releases/a2537ca3ab5b34d06f22fe0d66fb9463ba79b54c/v0.1.35/meshvps-install.sh.sha256). Ожидаемая сумма: `f612ea06f9529d48383b3e43f7d726ea487976645829ffa431cbc9d978c3d1ea`.

## Изменения и совместимость

В 0.1.35 защищён API управления Yggdrasil, исправлены права и ожидание блокировки установки, публичная GRE-регистрация использует подтверждение обратной доступности и ограниченный пул сессий. Запрос параметров не резервирует сессию. Публичная регистрация требует клиента 0.1.35; частные приглашения и ранее зарегистрированные устройства совместимы.

Обновление серверной части может перезапустить службы и прервать действующие подключения. Выполняйте его в подходящее время. GRE требует доступности IP-протокола 47 между ПК и VPS; это зависит от сети и хостинга.

[Соответствующие исходники сетевых компонентов](v0.1.35/network-sources.tar.xz), [манифест сборки](v0.1.35/network-build.json), [описание изменений](v0.1.35/MODIFICATIONS.txt). Исходники включают лицензии и зависимости для автономной пересборки Windows/Linux amd64 с Go 1.27.4. Содержимое файлов, загруженных сервером, закреплено SHA-256 в установщике.
